# Glass Statistics · 五种统计 UI

## 规格与方向
15 秒，1920×1080，60fps，128 BPM；无口播，合成配乐与短字幕。延续前作的左侧 Georgia 斜体大标题、中文短句、右侧单张图表、页眉页脚和编号结构。改为近黑背景、透过玻璃的流动光色、磨砂卡片、细边缘反光。图表颜色为薄荷、灰紫、冰蓝、浅金，文字保持清晰。

语言：card-montage。材料：代码绘制图表与黑色磨砂玻璃。背景光源在卡片背后移动，卡片通过裁剪背景模糊采样呈现透光；文字和数据单独清晰绘制。

## 数据检查
影片中所有数值为示例，页脚全程标记。

- 漏斗：12000 → 7200 → 3600 → 1800；相邻转化 60%、50%、50%，总转化 15%。高度使用相同线性比例。
- 桑基：来源搜索 60、社交 40；搜索流向阅读 36、购买 24，社交流向阅读 24、购买 16；流入流出均为 100，接收端阅读 60%、购买 40%，带宽按数值计算。
- 多环：设计 86%、开发 68%、测试 42%；各自以 100% 为目标，不能相加当作份额。
- 仪表：720 / 1000 = 72%，剩余 280；半圆弧长度与指针均对应 72%。
- 面积：直接访问 [12,15,13,20,22,27]，搜索 [8,11,10,14,17,19]，社交 [4,6,5,8,9,12]，单位千次；合计 [24,32,28,42,48,58]，坐标轴 0–60。

## 节奏与时间码
8 小节 × 4 拍 = 32 拍；每拍 0.46875 秒。切点与关键动作按节拍安排，不宣称所有切点都是小节首拍。

| 时间 | 画面 | 字幕 | 动作与声音 |
|---|---|---|---|
| 0–1.875 | 黑色玻璃五卡同时出现，已有完整可辨认形状 | Glass / 黑玻璃，让数据发光 / 15 秒 · 五种统计 UI | 首拍低频落点；光源透过卡片移动 |
| 1.875–4.219 | 漏斗依次收窄，阶段转化标签 | Funnel / 漏斗看转化 / 哪一步，人变少了？ | 四段逐拍显现，聚焦最后一段 |
| 4.219–6.563 | 桑基色带从左流向右，隔离一条来源 | Flow / 流向看去处 / 从哪里来，往哪里去。 | 带状流展开，细粒子沿路径移动；加深低频 |
| 6.563–8.906 | 三层同心进度环，聚焦开发 | Rings / 多环看进度 / 多个目标，各走多远。 | 圆弧错峰扫过，光标轻点图例 |
| 8.906–10.781 | 半圆仪表扫到 72%，指针停稳 | Gauge / 仪表看达成 / 离目标，还差多少。 | 扫描声、落点提示，短暂留白 |
| 10.781–13.125 | 三层渐变面积生长，游标扫描月份 | Layers / 面积看构成 / 总量变化，谁在推动？ | 横向揭示、游标与合计联动，节奏回升 |
| 13.125–15 | 回到五卡完整同屏，五个名称都有 | Clarity / 看见数字 / 也看清方向。 | 回归主和弦，完整尾音与淡出 |

能量：开场立刻可读 → 漏斗建立节奏 → 桑基流动高潮 → 圆环与仪表形成形状呼应 → 面积展开 → 五卡收束。所有中段卡片位置和尺寸一致，标题随编号替换；前后五卡排列一致。最复杂镜头为守恒带宽的桑基流和透光卡片，先验证它。

首帧 0.0、主镜头 5.2、信息密集 11.9、结尾 14.4；另取九帧总览，至少两轮检查后导出全片。检查文字无遮挡、五种齐全、图形比例、曝光与黑位。
