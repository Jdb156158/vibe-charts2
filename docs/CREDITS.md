# 参考与授权

视觉参考：[BoardUI](https://www.boardui.com/zh-hans) 公开图表展示。图形与交互独立编写，未使用 BoardUI Pro 源码。各图表来源见 [分镜与核对表](../film/treatment.md)。

版式延续 [vibe-charts1](https://github.com/Jdb156158/vibe-charts1)，本片改为黑色毛玻璃与薄荷、灰紫、冰蓝、浅金色图形。所有数值为合成演示数据。

Noto Sans SC 使用 OFL 授权，文件随附在 [film/assets/fonts](../film/assets/fonts/)。Georgia 使用系统字体，不分发字体文件。

GSAP 与 huashu-motion 运行时在 `film/vendor/`，保留第三方声明和授权文件。网页交互本身不依赖这两个库。本仓库不对第三方代码和字体授予额外授权。
